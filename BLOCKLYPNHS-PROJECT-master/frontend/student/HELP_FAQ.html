Open Activities in the sidebar, choose PHP, JavaScript, or C++, then select an activity. Build your solution with blocks and use Run to check its output.

Instead of typing code, you assemble ready-made blocks like puzzle pieces. Each block represents a real command (loops, variables, conditionals). It teaches the same logic as real programming.

Open Assessments & Modules from the sidebar. Choose Python or Java for assessments. Use the Modules button to browse lessons and module assessments.

Language assessments are separate graded tasks listed by number. Modules are guided lessons with an intro, lesson sections, a knowledge check, and a final assessment. Module results are stored separately from language assessment scores.

Open the LOOPS drawer and follow the task instructions. For the Python Loops module, the final task expects the numbers 1 through 5, each on its own line.

for i in range(1, 6): print(i)

Common causes: (1) missing the print/log block at the end, (2) blocks are not snapped together, (3) a red warning block upstream stopped execution. Check the console panel below the workspace.

Click the Preview button on the top-right of the workspace. The result panel renders your block structure as a live webpage.

Running code checks its output; it does not always submit or save a completed result. Finish the activity or use Submit Assessment for graded tasks, then check your score or notifications. If the result still does not appear, contact support.

Try a hard refresh (Ctrl+Shift+R). If you are on school Wi-Fi, some CDN assets may be blocked — ask your teacher to whitelist the site resources.

Each language assessment is worth up to 10 points. The automatic check compares your program output with the expected output. A correct match earns 10/10; a mismatch is recorded as 0/10 and shown as Not Passed. The score panel lists Assessments #1–#5 and a total out of 50.

On the Python or Java Assessments page, select View Score below Modules. The panel shows each assessment out of 10 and the total out of 50.

The Activities View Score panel groups completed activities by difficulty: Easy out of 20, Medium out of 20, and Hard out of 10, for a total of 50 points. Each activity can contribute up to 10 points.
