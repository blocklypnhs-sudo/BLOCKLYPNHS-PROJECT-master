1. What is PHP?

PHP stands for PHP: Hypertext Preprocessor. It's a server-side scripting language — the code runs on the web server, not the browser. PHP files end with .php and PHP code lives inside <?php ?> tags. 

index.php<?php
    echo "Hello, World!";
?>
OutputHello, World!
echo prints text to the output. Every PHP statement ends with a semicolon ;.

2. PHP Variables

In PHP, every variable starts with the $ sign. You don't need to declare the type — PHP figures it out. 

index.php$name = "Anna";   // string
$age  = 16;       // integer
echo $name;
OutputAnna
Common mistake: Don't write int $age = 16 in PHP — you just write $age = 16. PHP infers the type automatically.

3. Math Operations

PHP supports arithmetic with +, -, *, /. 

index.phpecho 80 - 50;   // subtract
echo 10 * 3;    // multiply
Output30 30

Worked Example

Follow along step by step. The Blockly blocks match the PHP code exactly.

Task: Store a student's name and age in variables, then print them in a sentence. 

index.php<?php
    $name = "Anna";
    $age  = 16;
    echo "My name is " . $name . " and I am " . $age;
?>
Expected OutputMy name is Anna and I am 16

Step-by-step explanation

  1. $name = "Anna" — creates a variable named $name and assigns it the string "Anna".
  2. $age = 16 — creates $age with the integer 16.
  3. The dot . is PHP's concatenation operator. It joins strings and variables together.
  4. echo prints the full sentence to the output.
Matching Blockly blocks: $name = "Anna" → $age = 16 → echo "My name is " . $name . ...
