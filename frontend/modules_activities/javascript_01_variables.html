1. What is JavaScript?

JavaScript is a client-side scripting language — it runs in the browser, not on the server. It makes web pages interactive. Every modern browser can run JavaScript.

You write JavaScript in a <script> tag or a .js file. Here's the basic structure: 

script.js// This is a comment
console.log("Hello, World!");
OutputHello, World!

2. Output with console.log()

console.log() prints text to the browser's developer console. It's the JS equivalent of PHP's echo. 

script.jsconsole.log("Hello, World!");
OutputHello, World!
Rules: Every statement ends with a semicolon ; (though JS is forgiving). Text must be wrapped in quotes — single '...' or double "...". JavaScript is case-sensitive.

3. Variables — let at const

In modern JavaScript, you declare variables using let (can be changed) or const (cannot be changed). No $ symbol — that's PHP! 

script.jslet name = "Anna";      // string
let age  = 16;          // number
const grade = 11;      // constant
console.log(name);      // prints Anna
OutputAnna
Rules: No $ prefix. Must start with a letter, _, or $ (but $ is discouraged). Case-sensitive: name ≠ Name. Cannot start with a number.

4. Math Operations

JavaScript uses +, -, *, / — same as PHP. 

script.jsconsole.log(25 + 15);   // add
console.log(80 - 50);   // subtract
console.log(10 * 3);    // multiply
Output40 30 30

5. Comparisons at if Statements

JavaScript uses the same comparison operators as PHP: >, <, ==, !=. Combine with if. 

script.jsif (20 > 10) {
    console.log("20 is greater than 10");
}
Output20 is greater than 10

6. For Loops

The for loop repeats code a set number of times. Modern JS uses let in the loop header. 

script.jsfor (let i = 0; i <= 4; i++) {
    console.log("I love programming!");
}
OutputI love programming! I love programming! I love programming! I love programming! I love programming!

Worked Example

Follow along step by step. The Blockly blocks match the JS code exactly.

Task: Store a student's name and score in variables, then print them in a sentence. 

script.jslet studentName = "Caryll";
let score = 90;

console.log("Student: " + studentName + " | Score: " + score);
Expected OutputStudent: Caryll | Score: 90

Step-by-step explanation

  1. let studentName = "Caryll" — store the string "Caryll".
  2. let score = 90 — store the number 90.
  3. JS uses + to join strings (unlike PHP which uses .).
  4. console.log prints the combined string.
