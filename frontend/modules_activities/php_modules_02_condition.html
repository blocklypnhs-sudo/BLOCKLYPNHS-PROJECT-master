1. What are Conditionals?

A conditional lets your program choose between different paths. Instead of running every line, PHP checks a condition first — if it's true, it runs one block; otherwise, it runs another.

2. Comparison Operators

These operators compare two values and return either true or false:

  • > — greater than
  • < — less than
  • >= — greater than or equal
  • <= — less than or equal
  • == — equal to (value only)
  • != — not equal
index.phpvar_dump(25 > 18);   // true
var_dump(10 == 20);  // false

3. The if Statement

An if statement runs a block of code only if a condition is true. 

index.php$score = 85;
if ($score >= 75) {
    echo "You passed!";
}
OutputYou passed!
Syntax rules: Condition goes inside parentheses ( ). Code block goes inside braces { }. No semicolon after the closing }.

4. Adding else

Use else to run a different block when the condition is false. 

index.php$score = 60;
if ($score >= 75) {
    echo "Passed";
} else {
    echo "Failed";
}
OutputFailed

5. Multiple Conditions with elseif

Use elseif to test more conditions before falling back to else. 

index.php$score = 85;
if ($score >= 90) {
    echo "Excellent";
} elseif ($score >= 75) {
    echo "Passed";
} else {
    echo "Failed";
}
OutputPassed
